# Generator Lembar Jawaban

Situs statis untuk menyusun lembar pilihan ganda A4, mengisi kunci jawaban, dan memeriksa hasil foto atau pindai di browser.

## Cara memakai

1. Isi mata pelajaran, tanggal, jumlah soal, dan kunci jawaban.
2. Pilih **Cetak lembar A4**. Gunakan kertas A4 dan skala 100%.
3. Minta siswa menghitamkan satu bulatan penuh dengan pensil 2B.
4. Buka **Periksa hasil pindai**, pilih foto JPG/PNG/WEBP/BMP, lalu periksa hasilnya. PDF perlu diubah menjadi gambar terlebih dahulu.
5. Tinjau jawaban yang ditandai ganda atau kurang jelas. Nama siswa diambil dari nama file foto dan dapat diedit.

Jumlah soal otomatis menata lembar menjadi 1 kolom untuk 1–30 soal, 2 kolom untuk 31–60 soal, dan 3 kolom untuk 61–120 soal. Ukuran bulatan ikut menyesuaikan ruang yang tersedia.

Semua pemrosesan foto dan penyimpanan kunci berlangsung di browser. Kunci pada alamat situs ini terpisah dari kunci yang disimpan ketika membuka file HTML secara lokal atau menggunakan browser lain.
